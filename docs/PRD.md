# 光影集产品需求

光影集是用于浏览国内摄影作品、学习构图的个人画廊。Astro 静态生成首页、周刊和作品详情，Vue 查看器负责详情交互。

## 设备与主题

- 桌面、平板和手机 H5 共用一个站点。画廊默认单列，视口宽度达到 640、1024 和 1600 像素时分别使用两至四列。
- 浅色和深色模式适用于全站。首次访问跟随系统，手动选择由当前浏览器保存。

## 作品浏览

- 页眉与浏览器标签页使用同一个站点图标，页眉提供 GitHub 仓库入口。
- 首页默认显示最新一期，可切换到任意已入库的周刊。周刊和作品使用各自的静态地址。旧版链接可以跳转到仍在收录的对应作品。
- 首页显示当期作品数量、作品名和摄影师。卡片保留照片画幅，多列时按最短列排列，并保持作品顺序与键盘访问顺序一致。
- 详情页优先显示九宫格辅助线、适应屏幕和原始尺寸。作品说明沿用原文，打开原图和分享位于说明下方。
- 画廊顺序同时用于详情中的上一张和下一张。查看大图时可用方向键操作或在照片上左右滑动。从画廊进入后返回原滚动位置。
- 作品链接包含独立 ID，可直接打开。图片加载失败或作品不存在时提供明确反馈。

## 周刊内容与发布

- 初始期选自小米徕卡全球影像大赛 2026 中国获奖作品，保留作者和官方出处。此前归档已移除。
- 周刊随仓库保存为 JSON。照片使用远端地址，记录原始像素宽高，并可提供不同宽度的同画幅缩略图。各端由浏览器选择尺寸并加载。
- 推送到 main 后，GitHub Pages 工作流校验并构建仓库中的 JSON。格式和样例见[周刊 JSON 格式](./issue-json.md)。
- GitHub Pages 是站点的自动部署渠道；关闭 Vercel Git 自动部署和 CodeRabbit 自动 PR 审查。
- JSON 可直接提交到 `main` 并触发构建发布，不要求经过 PR 合并。保留 Release Please 的版本发布 PR，仅管理版本号、CHANGELOG 和 GitHub Release，不阻塞内容上线。
