# 光影集产品需求

光影集是用于浏览国内与国际摄影获奖作品、学习构图的个人画廊。Astro 静态生成首页、周刊和作品详情，Vue 查看器负责详情交互。

## 设备与主题

- 桌面、平板和手机 H5 共用一个站点。画廊默认单列，视口宽度达到 640、1024 和 1600 像素时分别使用两至四列。
- 浅色和深色模式适用于全站。首次访问跟随系统，手动选择由当前浏览器保存。

## 作品浏览

- 页眉与浏览器标签页使用同一个站点图标，页眉提供 GitHub 仓库入口。
- 首页按日期倒序展示周刊时间线，同日国内与国际版桌面并排、手机堆叠。没有新增作品的版本显示状态，不复制往期作品。周刊和作品使用各自的静态地址。国内版使用期次日期，国际版使用同日期加 `-international`。
- 首页显示各版作品数量及入口。详情画廊展示作品名和摄影师。卡片保留照片画幅，多列时按最短列排列，并保持作品顺序与键盘访问顺序一致。
- 有图周刊的“选择期次”统一切换日期与国内、国际版本，菜单标明日期、版本和当前项；上一期、下一期仍在当前版本内切换。页眉站点标识返回首页，不另设顶部“返回周刊时间线 / 同日版本”导航行。
- 详情页直接加载 `picUrl` 原图，每张作品完整居中适配，不保存缩放与平移。原图加载并解码前，在画幅内显示占位；失败则显示错误反馈。右侧保留构图辅助线、黑白观察及其浏览器偏好，不再提供适应屏幕/1:1 尺寸开关。作品说明沿用原文，打开原图和分享位于说明下方。
- 画廊顺序同时用于详情中的上一张和下一张。查看大图时可用方向键操作或在照片上左右滑动。从画廊进入后返回原滚动位置。
- 作品链接包含独立 ID，可直接打开。图片加载失败或作品不存在时提供明确反馈。

## 周刊内容与发布

- 国内版与国际版按官方页面来源区分，各自收录具名获奖作品，不按摄影师国籍筛选。两版允许出现同一作品，赛事年份独立；去重只作用于同一版本、同一届的历史记录。
- 2026 年 11 月 16 日是首个周刊期次，收录小米徕卡全球影像大赛 2026 获奖作品。国内与国际版统一展示照片，卡片进入带构图辅助线、缩放和切图的作品查看器。照片保留原文说明、作者和官方来源。此前归档已移除。
- 周刊随仓库保存为 JSON。照片使用远端地址，记录原始像素宽高，并可提供不同宽度的同画幅缩略图。画廊由浏览器选择响应式尺寸；详情固定原图，避免缩放时切换图源。
- GitHub Actions 每周一北京时间 07:00、每次 `main` 推送及手动运行时检查国内与国际官方来源。本地与 CI 同步均按北京时间当周周一归档。周内首次发现新作品时创建该日期的增量期，后续新作品补入同一期。更正已有信息时保留原日期和作品 id。两版均无新增时可以跳过该周，定时检查无变化时跳过构建和发布。
- 周刊数据有变化时先校验、测试并构建，再自动提交 JSON 并在同次工作流发布。`main` 推送遇到同步失败且周刊文件完整时，仍按仓库内已有数据构建发布。维护方法见[每周 CI 更新任务](./weekly-update-task.md)，字段和样例见[周刊 JSON 格式](./issue-json.md)。
- GitHub Pages 是站点的自动部署渠道；关闭 Vercel Git 自动部署和 CodeRabbit 自动 PR 审查。
- JSON 可直接提交到 `main` 并触发构建发布，不要求经过 PR 合并。保留 Release Please 的版本发布 PR，仅管理版本号、CHANGELOG 和 GitHub Release，不阻塞内容上线。

## 详情画布

- 桌面精细指针设备（包括窄窗口）在画布内以触控板捏合或 Ctrl + 滚轮连续缩放，最小为完整适配，最大为适配的 8 倍；以鼠标位置为锚点，边缘受画布约束。
- 普通滚轮不触发缩放：适配时滚动页面，放大后平移画面；鼠标拖拽同样平移。双击放大一档（2 倍），再次双击复位。网格与照片共享变换。
- Z 放大/复位；画布聚焦后加减号缩放、0 复位，放大时方向键平移，适配时左右键切图。浏览器 Ctrl/Command 加减号保持原生行为。
- 移动端在画布内双指捏合缩放，跟随两指中心平移；双点放大或复位。完整适配时单指上下滚动页面、左右滑动切图，放大后单指拖动画面，捏合结束后不触发切图。画布之外保留浏览器原生手势。实际舞台宽高共同决定照片适配尺寸，竖图、横图、全景均不裁切。
